# AIショートスタジオ

Claude・ChatGPT・Geminiが分担して、字幕付きの縦型ショート動画（1080×1920 MP4）を自動で作るWebアプリです。スマホとPCのブラウザで動きます。

## しくみ

1. **Claude** が依頼文から企画・台本・画像の指示を作り、各シーンの役割（つかみ・本編・補足・締め）を決める
2. **ChatGPT**（OpenAIの画像モデル）が各シーンの画像を生成
3. **Claude** が画像をチェックし、問題があれば指示を直して ChatGPT に再依頼（足りない場面は追加）
4. **Gemini** がつかみと本編のシーンを動画にし、Claude がチェック
5. **Gemini** がナレーションを録音
6. **Claude** がテロップ（フォント・色・強調語・動き）とシーンの切り替え効果を演出
7. **Claude** が字幕入りの完成画面を通しでチェックし、OKが出るまで修正を繰り返す
8. OKが出たら、この端末で MP4 に書き出し

## 使い方

1. 「設定」で3つのAPIキーを入れる（キーはその端末のブラウザにだけ保存）
   - Claude: https://console.anthropic.com/settings/keys
   - OpenAI: https://platform.openai.com/api-keys
   - Gemini: https://aistudio.google.com/apikey
2. 「制作」で作りたい内容を書いて「制作スタート」
3. 「編集・書き出し」で確認・手直しして保存

APIキーなしで流れを試したいときは「デモモード」を使ってください。

## 注意

- 料金は各社のAPIの従量課金です（ChatGPT Plus などのサブスクとは別）。予算の上限を超えそうになると自動で止まります。表示される費用は目安です。
- OpenAIの動画API（Sora）は2026年9月24日に終了したため、動画はGeminiの動画モデルで作ります。
- モデル名は「設定」で変更できます。
- 書き出しは Chrome / Edge の最新版で最も速く動きます（H.264 + AAC）。
- 作業中の作品はブラウザ（IndexedDB）に自動保存され、「続きから再開」できます。

## ファイル

静的ファイルだけで動きます（ビルド不要）。GitHub Pages などにそのまま置けます。
